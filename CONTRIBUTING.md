# Contributing to Please Continue

Please Continue is public for source viewing and evaluation, but external
contribution intake is not open yet. The project is still establishing its own
governance, reporting channels, contributor terms, and release process.

Please do not open an unsolicited pull request. It may be closed without review
until the intake process is published. Issues and Discussions are also disabled
at this stage.

## Current source status

The repository is derived from Continue and is undergoing foundational work to
separate project-owned behavior and documentation from inherited assumptions.
During this stage:

- repository structure and component boundaries may change;
- build, packaging, runtime, and verification processes may evolve;
- inherited names, links, automation, and documentation may remain while they
  are reviewed;
- supported platforms and compatibility boundaries are not final; and
- incomplete or transitional documentation may not describe the latest source
  accurately.

Branches, workflow artifacts, and development packages are development
snapshots unless a specific release says otherwise. Do not infer a stability,
compatibility, support, or release commitment from inherited code or
documentation.

For source orientation, read [`README.md`](README.md),
[`BUILD_DEPENDENCIES.md`](BUILD_DEPENDENCIES.md), and [`TESTING.md`](TESTING.md).
The repository's [`LICENSE`](LICENSE) and applicable third-party notices govern
use and redistribution.
